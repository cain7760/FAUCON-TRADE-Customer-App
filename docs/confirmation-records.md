# 交易确认书

数据菜单的交易确认书沿用本端权益表格、筛选及深色主题。查询条件先编辑，点击查询或刷新后生效；默认及重置后的日期范围为近 7 天（含当天）；手动清空日期时查询截至今天的全部确认书记录。默认条件依次为日期范围、确认书文档编号、交易对手、主合约编号，其余条件在“更多”中。文档编号、主合约、确认书编号、合约编号、事件日期/类型、交易对手、交易簿、互换/业务类型、审批状态、操作用户和交易货币均可筛选，不包含邮件字段或邮件操作。

父节点代表一份完整确认书，子行仅展示事件明细。单份下载和勾选父节点后的批量下载均输出 ZIP，每份文档只打包一次；筛选到部分明细后下载仍是该父文档的完整 PDF。查询或重置会清理原选择，避免误下载隐藏记录。下载失败时不输出缺失文件的 ZIP。

当前为本地静态快照，尚未接入生产查询/文件服务。PDF 文件清单位于 `src/views/data/confirmationModel.js`，打包读取清单中的文件。
